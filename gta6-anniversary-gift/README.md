# 给畅畅宝的 GTA VI 周年礼物

这是一个无需安装依赖的静态网页。双击 `index.html` 即可预览；手机扫描二维码时，需要先将整个文件夹部署到公开网址。

## 生成正式二维码

部署完成后，将网址粘贴到 [QR Server](https://goqr.me/api/) 生成 PNG 或 SVG 二维码。建议误差纠正选 H、尺寸至少 800 × 800；印刷时在二维码四周保留白边。

可选的免费部署方式：GitHub Pages、Cloudflare Pages 或 Netlify Drop。上传 `gta6-anniversary-gift` 文件夹的全部内容后，以它给出的公网网址生成二维码即可。
